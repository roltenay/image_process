# Image Processing Application (Python)

A comprehensive Python application for image processing, filtering, and computer vision operations.

## 🛠️ Features & Operations
* **Basic Transformations:** Cropping, Resizing, Brightness & Contrast Adjustment
* **Filtering:** Mean, Median, and Gaussian Blurring / Noise Reduction (Salt & Pepper)
* **Histogram Operations:** Histogram Calculation & Stretching
* **Thresholding:** Binary and Adaptive Thresholding
* **Edge Detection:** Sobel and Gradient Operators
* **Morphology:** Opening, Closing, Dilation, and Erosion

## 💻 Tech Stack
* Python 3.x
* NumPy
* PIL (Pillow) / OpenCV

## 🚀 How to Run
```bash
python main.py
